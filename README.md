# 毎朝ニュース

介護・医療、福祉用具、宮城・仙台を重点的に確認する個人用ニュースWebアプリです。

- 一覧は2〜3行の要約見出し
- クリックで詳細・情報の段階・一次情報へのリンクを表示
- 公式サイトを優先し、取得できた記載だけを表示
- GitHub Actionsが日本時間の毎朝6:15に更新
- GitHub Pagesで無料公開

ニュース収集で十分な件数を確認できなかった日は、誤った空データで上書きせず、前回の表示を維持します。

公開・自動更新ともに稼働確認済みです（2026年10月3日）。

営業向けに「介護制度」「福祉用具」「宮城・仙台」「医療・安全」を分け、公式ページ本文の要点を表示します。

記事を選び、説明文付きの配布資料をスマートフォンからPDF保存できます。
