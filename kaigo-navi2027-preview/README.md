# 介護制度改正ナビ2027

採用済みの画面・公開先は https://taku80147-alt.github.io/maiasa-news/kaigo-navi2027-preview/ です。
旧 `kaigo-navi2027/` やリポジトリ直下のニュースアプリとは別です。

## 利用と費用

- ブラウザで開く静的サイト。ログイン・パスワード・Google連携は不要です。
- 公開GitHubリポジトリのGitHub Pagesと標準GitHub Actionsで運用。独自ドメイン、有料API、外部データベース、AI課金は使いません。
- お気に入りは各ブラウザのlocalStorageに保存。他端末との同期や営業担当者限定のアクセス制限は行いません。
- 本文までのキーワード検索、記事リンクのコピー、30秒・詳しく・営業の3段階、現行制度の学習に対応。
- 自動の制度回答生成はありません。「調べる」は掲載済み解説の検索です。

## 情報の扱い

現行制度、検討案、法律の公布済み事項を分けて表示します。法律の公布と施行日、原則日と項目別の例外、法律と報酬改定を混同しません。記事の根拠はPDFのページリンクから確認できます。

原文PDFの全ページ文字、表候補、注記・例外候補を取得し、原本のハッシュと宣言された根拠・数値のページを照合します。記事本文のハッシュも照合し、根拠監査と本文がずれた記事は詳細解説に採用しません。

これらの機械検査は、全文の法的解釈、図表の意味、網羅性、最新法令との完全な一致を自動保証するものではありません。編集した記事は人が原文を対照します。自動収集された未審査PDFは解説として自動公開しません。各記事の確認日と検証範囲を表示します。

## 開発・確認

必要な無料ライブラリ：

```sh
python -m pip install pymupdf==1.26.5 beautifulsoup4==4.13.4
python scripts/build_kaigo_explainers.py
python -m unittest discover -s scripts -p 'test_kaigo_*.py' -v
```

PyMuPDFのライセンスはAGPL-3.0／商用ライセンスの二択です。本リポジトリでは無償のOSS版を検証スクリプトで使用し、商用ライセンスや有料推論を要求しません。第三者が再配布・組み込む場合はライセンス条件を確認してください。

PDF原本・抽出結果は `KAIGO_EVIDENCE_DIR` へ出力します。省略時はGit管理対象外の `.kaigo-evidence/`。CIではrunnerの一時領域を使用し、原本・抽出結果を7日間のActions artifactとして保持します。表の抽出漏れや読取不能は手動確認の対象です。

### 更新手順

1. 公式の通知・会議資料を確認。会議の開催・議題だけで制度変更の成立を断定しない。
2. `data/explainers.json` の対象・例外・現行／変更・営業説明とページ根拠を編集。資料原本のSHA256を固定する。
3. ビルドで `explainers-verified.json` を生成し、テストに通す。記事と検証済みJSONを一緒に反映する。
4. Pages公開前のCIで全記事、保存、検索、リンク、通信失敗時の表示を確認。320/360/390/430pxで横はみ出しを検査し、採用済みバナー・特集・日替わりカードは変更前と画像比較する。
5. 画面スクリーンショットを確認し、Pages公開成功を確認する。

公式会議一覧のチェックは日本時間07:10、未審査PDFの収集は07:45、原文再検証は毎週日曜06:20の予定です。GitHubのスケジュール実行には遅延があります。変更のない日は記事日付を「今日」に書き換えません。

公開は `pages.yml` のデータ・操作・画面検査に成功した場合に進みます。日次の会議一覧更新と週次の検証済み解説更新も、保存した版を同じPages検査へ渡してから公開します。週次にデータ変更がなければ再公開しません。原本が変わった場合は解説の追加公開を止め、前回の公開データを保持して再確認します。
